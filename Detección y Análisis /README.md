# Detección y Análisis

La fase de Detección y Análisis corresponde a una etapa fundamental del proceso de Respuesta a Incidentes de Seguridad (Incident Response).

Su propósito es identificar actividades sospechosas, detectar posibles amenazas, analizar eventos de seguridad y determinar si estos representan un incidente que pueda comprometer la confidencialidad, integridad o disponibilidad de los sistemas y la información.

Durante esta fase se recopilan y analizan registros (logs), alertas de seguridad, indicadores de compromiso (IoC) y evidencias provenientes de diferentes fuentes de información.
